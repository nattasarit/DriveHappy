วางคุกกี้ YouTube (แอดมิน)

เบราว์เซอร์บนโดเมนนี้ อ่านคุกกี้ของ youtube.com ไม่ได้ (กฎ same-origin) — ล็อกอินในแท็บ YouTube อย่างเดียวไม่พอ ต้อง export แล้ววาง ให้เซิร์ฟเวอร์

  1. ตั้ง YOUTUBE_COOKIE_ADMIN_TOKEN ใน Hostinger hPanel แล้ว Redeploy/Restart
  2. บนคอม (ตอนจอด): เปิด youtube.com แล้วล็อกอิน Google
  3. บังคับต้องมีชื่อคุกกี้เหล่านี้ (ค่าอย่างน้อย):
    • SID หรือ __Secure-3PSID
    • SAPISID หรือ __Secure-3PAPISID ← สำคัญมาก (ใช้ทำ SAPISIDHASH)
    แนะนำเพิ่ม: HSID, SSID, APISID, LOGIN_INFO, VISITOR_INFO1_LIVE
  4. Chrome/Edge: F12 → Application → Cookies → https://www.youtube.com → คัดลอกเป็นบรรทัดเดียว SID=...; __Secure-3PSID=...; SAPISID=...; __Secure-3PAPISID=...; HSID=...; SSID=...; APISID=...; LOGIN_INFO=... · หรือใช้ส่วนขยาย cookies.txt แล้ววางทั้งไฟล์ (ดีกว่า เพราะครบชื่อ)
  5. ใส่โทเคน → วางคุกกี้ → บันทึก (ระบบจะปฏิเสธถ้าขาด SAPISID)
  6. ตรวจ /api/youtube/status → cookiesConfigured: true และ cookieCompleteness.complete: true แล้วลองเล่นในรถ

หมายเหตุ: คุกกี้แค่ 4 ตัวแบบ SID/HSID/SSID/__Secure-3PSID ไม่พอ — ANDROID_VR ไม่ใช้คุกกี้เบราว์เซอร์ ต้องใช้ WEB + SAPISIDHASH
